# Passo a passo para publicação no Streamlit Community Cloud

1. Entrar em [share.streamlit.io](https://share.streamlit.io) com o GitHub e dar acesso a repositórios privados;
2. **Create app**: 
   - Repositório: `tiagoguilhermino/hackathon`
   - Branch: `main`
   - Arquivo principal: `vila-de-personas/app.py`
3. **Advanced settings**: 
   - Python 3.12
   - Nenhuma chave em Secrets;
4. **Deploy**;
5. Em **Settings → Sharing**, deixar o app público;
6. Testar numa janela anônima e no celular, usando o botão "Carregar resultado salvo".

> **Nota:** O app usa a API da Groq (não a do Devin).
